## Progress Log
- **2026-10-26:** Published an [incident write-up](writeups/03-macos-persistence-malware.md) on the macOS malware I found and removed from my own laptop in September: 29 fake "Apple" LaunchAgents, hidden screen-capture components, and base64-encoded download commands injected into my shell configuration that reinstalled the infection on every launch. Reconstructed the timeline from file timestamps (initial compromise Aug 5 at 12:57, contained Sep 21 at 08:50, a 47-day exposure window), ruled out Chrome as the delivery path by correlating browser history against the infection time, and mapped the behavior to MITRE ATT&CK. Ran a five-week follow-up persistence audit (launchd, login items, configuration profiles, cron, system extensions) that confirmed no recurrence, triaged a false positive caused by an overly broad search, and removed unused camera-access apps and a root-level helper to shrink the attack surface.
- **2026-10-26:** Shipped [php-guardian v1.1](https://github.com/jeffreyesdavid/php-guardian), fixing a false positive in my own scanner: v1.0 flagged Ubuntu's PHP 8.3.6 as vulnerable by version number, but Ubuntu had backported the fix. v1.1 reads dpkg and rpm package changelogs for the CVE identifiers and reports `PATCHED-DISTRO` when the fix is present. Validated on a live Ubuntu 24.04 system. 20 tests.
- **2026-10-26:** Launched the [Aegis Guardian scam checker](https://jeffreyesdavid.github.io/aegis-guardian/app/): a mobile-friendly, English/Spanish page that runs entirely on the user's device. Added rules for family-impersonation ("Hi Mom, new number"), move-to-WhatsApp, brand-plus-link spoofing and "wrong number" openers, plus Spanish coverage. Built the AI layer on Meta's Muse Spark with schema-locked output and prompt-injection defenses, keeping the API key local and the server bound to localhost. 23 tests, plus a parity test keeping the browser and Python engines in sync.
- **2026-10-25:** Assessed my exposure to a newly disclosed AI-agent risk: Claude Code links each commit to its session, and a session set to Public exposes its full transcript. Found session links in 29 commits across my public repositories, scanned all eight repositories' full history with gitleaks (one finding, triaged as a false positive: a public USDC contract address in test data), disabled session links globally and per repository, and installed pre-commit secret scanning so keys are blocked before they are ever committed. See [write-up](writeups/02-ai-session-link-exposure.md).
- **2026-10-24:** Applied to the **Meta Global AI Developer Hackathon** (indie dev track, Oct 26 – Nov 4) with Aegis Guardian: a free, bilingual (English/Spanish) AI scam shield that reads suspicious texts and screenshots, explains the red flags in plain language and tells people what to do next. The pitch is grounded in the FBI's 2025 IC3 report: a record $20.9B in reported losses, 85% from scams rather than hacks, and $7.75B lost by people 60 and over.
- **2026-10-24:** Rewrote the [Aegis Guardian](https://github.com/jeffreyesdavid/aegis-guardian) README around a two-layer design: the local, offline rule engine runs first, then an AI layer (Meta's Muse Spark) handles what rules can't, like screenshots and new scam scripts. Documented the privacy trade-off plainly: the rule engine never touches the network, while the AI scanner only sends what the user chooses to scan.
- **2026-10-23:** Shipped Phase 1 of [Aegis Guardian](https://github.com/jeffreyesdavid/aegis-guardian), a consent-first safety and anti-scam agent designed so it can never become stalkerware. Phase 1 is a local, read-only scam shield that scores text messages and explains why each one was flagged: fake-recruiter "task scams," "text a different number" tricks, false urgency, high-pay bait, crypto and gift-card requests, and link shorteners. Python standard library only, no network, 16 tests. Wrote a threat model covering phone theft, server breaches, malicious contacts and abusers trying to enable silent tracking.
- **2026-10-22:** Built and shipped [ai-guardian](https://github.com/jeffreyesdavid/ai-guardian) ([project page](https://jeffreyesdavid.github.io/ai-guardian/)), a free, local "shadow AI" scanner inspired by CrowdStrike's Falcon Guardian announcement at Fal.Con 2026, but built for individuals and small businesses. It discovers AI apps, coding agents, AI browser extensions, local model servers and MCP servers (the plugins that connect agents to files and accounts), then flags risky setups: plain-text API keys, agents with access to the whole drive or `~/.ssh`, permission prompts turned off, unpinned or unencrypted MCP servers, and local AI servers exposed to the network. Read-only, secrets always masked, Python standard library only. 23 tests.
- **2026-10-22:** Ran ai-guardian against my own Mac: it found 16 AI agents and 1 medium risk (an AI browser extension with access to every website). The real-world run also exposed 3 bugs that tests on fake data missed (duplicate extension versions, noisy helper processes, and a macOS system service misread as an AI app), so I fixed them and added regression tests. Test fixtures build fake API keys at runtime, so no secret-looking strings ever land in the public repo.
- **2026-10-22:** Built and shipped [php-guardian](https://github.com/jeffreyesdavid/php-guardian) ([project page](https://jeffreyesdavid.github.io/php-guardian/)) the day after CISA's alert on "php2shell" (CVE-2026-109618 / CVE-2026-109619), critical PHP flaws allowing unauthenticated remote code execution. It handles CISA's first step, inventory: finds PHP installs in common hiding spots, flags vulnerable and end-of-life versions against the patched releases, and outputs JSON for SIEMs and CI. Read-only, with no exploit code. 16 boundary tests. During testing it flagged PHP 8.3.6 on an Ubuntu machine as vulnerable, which later proved to be a false positive (see 2026-10-26).
